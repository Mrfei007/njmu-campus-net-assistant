NJMU校园网自动化连接程序 1.4.3
使用说明

一、安装与首次设置
1. 适用于 Windows 10/11 x64。下载完整 ZIP 并全部解压，运行“NJMU校园网自动化连接程序.exe”。不要只复制 EXE，也不要在压缩包内运行。
2. 输入校园网账号、密码，选择连接方式；网页认证需同时选择运营商。
3. 按需设置自动化功能，点击“保存设置并更新自动化”，完成管理员授权。之后无需一直打开主界面。
4. .sha256.txt 仅用于可选的下载完整性校验，不是运行所需文件，可以不下载。

二、选择连接方式
全校无线：先用 Windows 连接一次 NJMU_WLAN 并保存配置。浏览器认证优先 Chrome，未安装时使用 Edge。“实验：优先尝试无浏览器登录”默认关闭；开启后预检不兼容时回退浏览器，已提交但结果不明时不重复提交。
宿舍有线：接好宿舍网线，选择对应连接方式和运营商，等待网络就绪后认证。
工位有线：先安装学校提供的锐捷客户端 V4.99.20131213，在程序中选择 RuijieSupplicant.exe。工位与宿舍不能混用；发布包不附带学校客户端或驱动。

首次启用工位原生认证：
1. 确认官方客户端能正常联网，在本程序保存账号和锐捷客户端路径。
2. 点击“检查原生认证设置…”，按提示完成环境检查。
3. 验证前用官方客户端注销，保持网线连接，再点击“验证并启用原生锐捷认证”。验证成功后才启用原生自动认证。
4. 保留学校客户端安装的驱动和后台服务。“原生认证失败时使用官方客户端兜底”默认关闭，可按需启用。官方客户端界面回退操作期间，请勿使用鼠标键盘。

三、自动化与日常操作
开机后自动联网：登录 Windows 后按保存的模式联网，不会主动唤醒电脑。
每天定时唤醒：按设定时间唤醒，再由后台检查联网；已在线不重复认证，离线时尝试恢复。它与开机联网开关独立。
每天定时休眠：按设定时间休眠，可单独开启或关闭。
联网后启动 UU：选择本机 UU 程序位置，联网成功后自动启动。

“立即认证并检查联网”：离线时进行一轮认证，已联网时不重复提交。
“断开校园网认证”：确认断开后暂停自动恢复 5 分钟，避免立即重新联网。
“打开日志”：查看运行记录。遇到问题先检查账号、网线或 Wi-Fi，以及所选连接方式；工位驱动未就绪时，确认学校客户端安装完整，必要时手动打开官方客户端。

四、升级、退出与停用
升级时解压到新文件夹，退出旧界面，从新目录启动并保存设置以更新任务路径；不要覆盖正在运行的文件。
“退出界面（自动化继续）”只关闭界面，后台任务仍运行。
停用或卸载前，选择“停止自动化并退出”，或先“停用全部自动化…”，再退出并删除完整文件夹。停止工位保活可能影响当前连接；账号、配置和日志会保留。

本程序不是学校官方客户端，未使用商业代码签名证书，首次运行可能出现 Windows 提示。
