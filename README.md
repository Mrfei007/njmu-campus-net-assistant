# NJMU 校园网自动化连接程序

面向南京医科大学 Windows 用户的校园网辅助工具，支持自动登录、断联恢复和可选的定时唤醒/休眠。当前版本为 `1.3.1`。

> 本项目不是学校官方客户端。使用前请确认符合学校网络管理规定。

## 支持的连接方式

- `NJMU_WLAN` 全校无线网；
- 宿舍有线网网页认证；
- 工位有线网（需预先安装学校提供的锐捷 V4.99 客户端）。

程序可按需启用开机后自动联网、后台监测、定时唤醒/休眠，以及联网后启动 UU。

## 运行环境

- Windows 10/11 x64；
- Microsoft Edge；
- 无线模式需能搜索到 `NJMU_WLAN`；
- 工位模式需安装并能够正常打开已支持版本的学校锐捷客户端。

程序未使用商业代码签名证书，首次运行可能出现 Windows SmartScreen 提示。

## 使用方法

1. 解压完整发布包，不要只复制 EXE，也不要直接在压缩包内运行；
2. 启动 `NJMU校园网自动化连接程序.exe`；
3. 输入校园网账号和密码，选择连接方式；
4. 按需设置自动联网、唤醒、休眠和 UU；
5. 点击“保存设置并更新自动化”，并同意创建计划任务所需的管理员授权。

更完整的操作说明见 [使用说明.txt](使用说明.txt)。

## 连接与恢复原则

- 使用真实联网探测确认连接状态，不把页面点击或进程退出当作登录成功；
- 自动恢复具有重复失败确认、提交频率限制和跨进程互斥保护；
- 宿舍有线模式不会切换 Wi-Fi 或重启网卡；
- 工位模式会区分系统出口异常与认证会话失效，避免仅因 VPN/TUN 路由变化重复认证；
- 手动注销成功后会暂停自动恢复 5 分钟，避免立即重新登录。

## 工位有线模式

工位模式与宿舍网页认证完全独立。程序会核验官方客户端文件、驱动、进程和窗口，仅在现场验证成功后允许后台认证。

原生认证兼容资料经过脱敏并与已验证的 `8021x.exe` 版本严格绑定。项目不包含锐捷 DLL、驱动、原始抓包或学校客户端；不支持的版本会直接停止认证。具体操作见 [使用说明.txt](使用说明.txt) 中的“首次启用工位原生认证”。

## 隐私

- 密码只保存在当前 Windows 用户的 Credential Manager；
- 配置、日志和发布包不保存密码；
- 日志过滤密码、IP、MAC 和认证报文等敏感信息，并保留 7 天；
- 本机配置、日志和诊断位于 `%LOCALAPPDATA%\NJMUCampusNetAssistant`，不会进入发布包或 Git 仓库。
