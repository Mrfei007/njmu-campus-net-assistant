# NJMU 校园网自动化连接程序

面向南京医科大学 Windows 用户的校园网辅助工具，支持无线、宿舍有线和工位有线认证，以及后台监测、断网恢复和定时任务。已上传的可运行版本为 **1.4.3**。

相对仓库此前的 1.3.1 发布，主要包括：

- 浏览器认证优先使用 Google Chrome，未安装时使用 Microsoft Edge。

## 连接与自动化

| 功能 | 行为 |
| --- | --- |
| 全校无线 | 使用 Windows 保存的 NJMU_WLAN 配置，按所选认证策略登录并检查真实联网 |
| 宿舍有线 | 网口就绪后执行网页认证，提交账号密码并选择运营商 |
| 工位有线 | 使用已验证版本的锐捷客户端组件；原生认证需要先通过环境检查和现场验证 |
| 开机后自动联网 | 登录 Windows 后按保存的连接模式自动联网；不会自行唤醒电脑 |
| 每天定时唤醒 | 到点唤醒，向后台监测交接联网确认请求；已在线不重复认证，离线按原流程恢复 |
| 每天定时休眠 | 按独立设置的时间休眠 |
| 联网后启动 UU | 联网成功后启动用户选择的本机 UU 程序 |

开机联网与每日唤醒是两个独立开关。Wake 任务投递请求，Monitor 统一执行自动认证；不能把开关名“每天定时唤醒”理解为唤醒后完全不检查联网。

程序通过真实联网探测确认状态。手动注销成功后暂停自动恢复 5 分钟，工位模式不会仅凭 VPN/TUN 路由变化或一次保活发送失败就重复认证。保活发送调用成功也不等于服务器已确认收到。

## 使用方法

运行环境为 Windows 10/11 x64。网页认证需要 Chrome 或 Edge；工位模式还需要本机已安装学校提供且受支持的锐捷 V4.99 客户端。项目不附带学校客户端、第三方锐捷 DLL 或驱动。

1. 将完整 ZIP 解压到长期存放的文件夹，不要只复制 EXE，也不要在压缩包中直接运行。
2. 打开 `NJMU校园网自动化连接程序.exe`，填写账号密码并选择连接方式。
3. 工位模式先选择本机 `RuijieSupplicant.exe`，再按说明检查与验证原生认证。
4. 按需设置开机联网、定时唤醒、定时休眠及 UU 路径。
5. 点击“保存设置并更新自动化”，完成计划任务所需的管理员授权。

完整操作、升级、停用和排查说明见 [1.4.3 使用说明](releases/1.4.3/使用说明.txt)。本程序不是学校官方客户端，且没有商业代码签名证书。
