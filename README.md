# NJMU 校园网自动化连接程序

面向南京医科大学 Windows 用户的校园网辅助工具：保存账号后自动认证登录、后台保活、
断网自动重连，可选开机联网、定时唤醒、定时休眠。

## 1.5.9.2 更新内容（相对上一次公开的 1.4.3）

- **工位有线不再需要学校锐捷客户端。** 1.4.3 要装锐捷 V4.99、在程序里选客户端路径，
  再走一遍环境检查和验证；现在改用程序自带的原生认证，认证后每 30 秒后台保活，不需要抓包。
- **工位断网后会自动恢复。** 网线被拔掉时停止保活并等待，插回后自动重新认证，一般两分钟内恢复。
  1.4.3 没有这套链路监测。
- **后台保活会自己看住。** 检测到保活确实停了会自动重建；保活状态显示在界面上，
  状态不对时能看出来（1.5.7 起）。
- **修掉工位"后台保活已退出"的误报**，以及它引起的约每 10 分钟断网重连（1.5.9.2）。
  如果你之前被"每十分钟掉一次"困扰，这一版就是修它的。
- **安装包内已随附 Npcap 1.89**（`tools\npcap-1.89.exe`，官方签名版），
  工位首次配置不用再另外找安装包。
- **界面调整**：窄高窗口、图标与文字层级重排，维护页统一为"打开日志"一个入口（1.5.9）。
- **锐捷客户端改为可选**：装了官方客户端的机器可以勾选"锐捷驱动作为后备连接"，
  只借用其驱动组件，不会启动客户端。

无线与宿舍的行为和 1.4.3 一致：无线优先 Chrome、没有则用 Edge，"实验：优先尝试无浏览器登录"仍默认关闭；宿舍仍是网页认证。
## 安装与首次设置

1. **解压完整文件夹**到固定位置（例如 `D:\NJMU\1.5.9.2\`），运行里面的
   `NJMU校园网自动化连接程序.exe`。
   不要只复制 EXE，也不要直接在压缩包里双击运行。
2. 输入校园网**账号、密码**，选择连接方式；网页认证还需要选择**运营商**。
   密码保存在 Windows 凭据管理器里，不写进配置文件。
3. 按需设置自动化功能，点击 **"保存设置并更新自动化"**，同意管理员授权（用于创建计划任务）。
   设置好之后不需要一直开着主界面。
4. 工位有线还需要两步一次性准备：安装 Npcap（包内 `tools\npcap-1.89.exe`），
   然后做一次 **"原生认证检查并验证"**——要先断开校园网认证，在离线状态下完成验证。

## 三种连接方式

| 模式 | 适用场景 | 首次准备 |
|---|---|---|
| **全校无线** | 教学楼、图书馆等 `NJMU_WLAN` 覆盖区域 | 先用 Windows 手动连接一次 `NJMU_WLAN` 并保存配置；浏览器认证优先 Chrome，未安装时用 Edge |
| **宿舍有线** | 宿舍网口 | 接好网线，等 IPv4、网关、DNS 就绪后认证，按提示选运营商 |
| **工位有线** | 工位网口（原生认证） | 安装 Npcap，并完成一次"原生认证检查并验证"；**不需要**安装锐捷客户端，**不需要**抓包 |

工位有线使用程序自带的原生 Npcap 认证，每 30 秒后台保活；拔掉网线会停止保活并等待，
插回后自动重新认证（最长约 2 分钟）。

宿舍与工位不能混用；两种有线模式都要求对应网口已接好网线。

## 日常使用

| 功能 | 行为 |
|---|---|
| 开机后自动联网 | 登录 Windows 后按保存的模式联网，不会主动唤醒电脑 |
| 每天定时唤醒 | 到点唤醒电脑，由后台检查联网；已在线不重复认证 |
| 每天定时休眠 | 按独立设置的时间让电脑休眠 |
| 联网后启动 UU | 选择本机 UU 程序位置，联网成功后自动启动 |

界面上三个常用按钮：

- **立即认证并检查联网**：用已保存的凭据执行一次认证并验证真实联网。
- **断开校园网认证**：按当前实际在用的网络执行注销，确认离线后**暂停自动恢复 5 分钟**，
  避免立刻又连回去。
- **打开日志**：查看运行记录；遇到问题先核对账号、网线/无线和所选连接方式。

开机联网、定时唤醒是**两个独立开关**，可以只开其中一个。

## 换电脑、升级与停用

- **换电脑**：解压即用。每台电脑需要自己保存一次账号密码（存在该用户的 Windows 凭据管理器），
  配置和日志不随发布包携带。无线模式要先手动连过一次 `NJMU_WLAN`；工位模式要把 Npcap 装一次。
- **升级**：解压到**新文件夹**，先退出旧界面，再从新目录启动并保存设置（更新计划任务路径）；
  不要覆盖正在运行的文件。升级后如果"原生认证检查并验证"再次出现，说明原生验证需要重做，
  请先断开校园网认证再验证一次。
- **退出界面（自动化继续）**：只关闭窗口，后台任务仍在运行。
- **停用/卸载**：选择"停止自动化并退出"（或先"停用全部自动化"），再退出并删除整个文件夹。
  账号、配置和日志会保留，需要时手动清理。

## 常见问题

**Q：界面上"原生认证检查并验证"又出现了？**
程序或 `NpcapBridge` 更新过、验证状态丢失时，这个按钮会重新出现；未验证期间后台自动认证会暂停。
按提示先断开校园网认证，离线完成一次验证即可恢复。

**Q：提示"组件版本不匹配"？**
说明只替换了 EXE、没换完整目录（1.6 起主程序与桥接必须成对升级）。重新解压完整发布包再运行。

**Q：明明连着网，却显示"后台保活已退出"？**
1.5.9.2 已修复该误报。如果仍看到，先看状态文案里的"已成功发送次数"和
`diagnostics\native-keepalive-*.jsonl` 的退出原因，再考虑重新验证。

**Q：每 10 分钟断一下网？**
1.5.7–1.5.9.1 的已知问题（看门狗误杀健康会话），1.5.9.2 已修复。请升级到 1.5.9.2。

**Q：账号密码存在哪里？**
Windows 凭据管理器（凭据目标以 `NJMU` 开头）。程序不写明文配置文件，也不上传账号信息。

**Q：需要一直开着界面吗？**
不需要。"保存设置并更新自动化"成功后，界面可以关闭，后台任务继续运行。

**Q：为什么首次运行弹 Windows 安全提示？**
程序没有购买商业代码签名证书。确认下载来源与 SHA-256 后再运行。

**Q：宿舍无线能用"无浏览器登录"吗？**
"实验：优先尝试无浏览器登录"默认关闭，仅用于全校无线；宿舍有线仍使用网页认证。

## 系统要求

- Windows 10 / 11 x64
- 网页认证（无线、宿舍）：Chrome 或 Edge 之一
- 工位有线：Npcap（安装包已随发布包提供，也可从 npcap.com 获取）；可选安装官方锐捷客户端并
  启用"锐捷驱动作为后备连接"（只使用其 Rawether 驱动组件，不启动锐捷客户端）

---

## 数据与安全

- 账号密码保存在 **Windows 凭据管理器**，不写入配置文件、不随发布包携带、不上传。
- 程序会在本地创建计划任务（开机联网/定时唤醒/定时休眠）、读写状态文件与日志；
  日志位于程序目录的 `diagnostics\` 下，可用界面上的"打开日志"查看。
- 除校园网认证所需的请求外，程序不收集、不上报任何使用数据。
