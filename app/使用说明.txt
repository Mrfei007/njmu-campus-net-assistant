NJMU校园网自动化连接程序 {{VERSION}}
使用说明

一、安装与首次设置
1. 适用于 Windows 10/11 x64。解压完整文件夹后运行其中的 EXE；不要只复制 EXE，也不要在压缩包内运行。
2. 输入校园网账号、密码，选择连接方式；网页认证还需选择运营商。
3. 按需设置自动化功能，点击“保存并应用”，完成管理员授权。之后无需一直打开主界面。
4. .sha256.txt 仅用于可选的下载完整性校验，不是运行所需文件。

二、选择连接方式
全校无线：先用 Windows 连接一次 NJMU_WLAN 并保存配置。认证默认走无浏览器直连（已无需手动开启），遇到不兼容时自动回退 Chrome，未安装 Chrome 时用 Edge；回退发生在提交凭据之前，不会重复提交密码。
宿舍有线：接好宿舍网线，等待 IPv4、网关和 DNS 就绪后认证，按提示选择运营商。
工位有线：程序使用本程序的原生 Npcap 认证完成联网，并每 30 秒后台保活，不需要安装锐捷客户端，也不需要抓包。
  · “网络连接”栏的“原生认证检查并验证”只在工位有线尚未验证时显示；需先断开校园网认证，再离线完成一次真实验证。成功后底部提示，失败会弹出可复制详情的说明框；验证通过后该位置恢复为“立即认证并检查联网”（在线时为“断开校园网认证”）。
  · 程序或 NpcapBridge 更新、验证状态丢失时，该按钮会再次出现，需要重新验证；未验证期间后台自动认证会暂停。
  · 若检测到后台保活确实已不存在但网络仍在线，程序会连续两次观测确认（约 4 分钟）后重建保活；失败按 10 分钟起步的退避间隔重试，并在运行日志中记录原因。
  · 1.6 起“保活状态”分为三种：运行中（有近期成功发送或进程持有会话锁）、已退出（进程不存在且无人持有会话锁、记录已过期）、无法判定（其它情况）。只有“已退出”会触发自动重建；“无法判定”只记一条日志，不会杀进程重连，避免误杀健康会话。
  · 1.6.1 起，桥接程序报告“链路断开”或本机网线未就绪时，程序会把探测间隔从 2 分钟缩短到约 15 秒，更快确认是否真的断网；但在网线/网络就绪之前只做探测，不会反复发起认证，链路恢复后按原有流程自动重新联网。
  · 1.6.2 起，即使在两轮监测之间的等待期，程序也每 5 秒看一眼保活记录；一旦发现“链路断开”，立即开始下一轮探测，并跳过第二次确认探测，通常几秒到十几秒即可判定断网。
  · 1.6.3 起，网线插回后同一轮探测里就会确认“认证会话需要重建”并立即恢复联网（不再先等约三分钟确认故障）。
  · 1.6.4 仅删除“查看联网详情”按钮，运行状态统一在“维护”页查看；连接、保活和计划任务逻辑与 1.6.3 相同。
  · 同一时间只允许一个保活会话：重复启动的桥接会以“已有会话在运行”退出，不会出现两个进程互抢。状态记录同时带有进程创建时间与心跳序号，便于区分“真的退出”和“状态文件过时”。
  · 后台保活的退出原因同时写入 diagnostics\native-keepalive-YYYY-MM-DD.jsonl，便于排查“保活状态未知/已退出”等问题。
  · 首次选择“工位有线网”时，程序会检查本机是否已安装 Npcap；未安装会弹窗，让你从随程序提供的安装包中选择安装。安装包请与程序一并保存（例如放在程序的 tools 文件夹），安装完成后点“重新检测”。
  · 本程序在 `tools` 文件夹内附带官方签名版 Npcap 1.89 安装程序（`tools\npcap-1.89.exe`）；如该文件缺失，请向发放者获取。安装时保持默认选项、一路“下一步”即可。
  · 如本机另外安装了学校锐捷客户端，可勾选“锐捷驱动作为后备连接”。它只使用官方锐捷的 Rawether 驱动组件，不会启动锐捷客户端；勾选后需先点击“锐捷驱动检查”完成一次只读检查，未通过则不会启用后备连接。
  · 宿舍与工位不能混用；两种模式都要求对应网口已接好网线。

三、自动化与日常操作
开机后自动联网：登录 Windows 后按保存的模式联网，不会主动唤醒电脑。
每天定时唤醒：按设定时间唤醒电脑，再由后台检查联网；已在线不重复认证。
每天定时休眠：按设定时间让电脑休眠，可单独开关。
联网后启动 UU：选择本机 UU 程序位置，联网成功后自动启动。

“立即认证并检查联网”：在工位原生认证验证有效后，用已保存的凭据执行一次原生认证并验证真实联网（Npcap 优先，锐捷驱动后备仅在已启用并通过检查时尝试）；如界面上的连接方式已改但未保存，会先询问是否保存并应用。
“断开校园网认证”：按当前实际在用的网络执行注销（与界面上未保存的选择无关），确认离线后暂停自动恢复 5 分钟。暂停期内点击“保存并应用”会先确认；确认并成功保存任务后取消该暂停，保存或任务安装失败则保留暂停。
“打开日志”：查看运行记录；遇到问题先核对账号、网线/无线和所选连接方式。

工位有线会自动监测链路：拔掉网线时停止保活并等待，插回后自动重新认证，最长约 2 分钟。

四、换一台电脑使用
1. 解压即用：全校无线、宿舍有线。无线默认无浏览器认证，宿舍网页认证需要该电脑装有 Chrome 或 Edge；无线保留一个 Chrome 或 Edge 用于自动回退更稳妥。
2. 工位有线：把 Npcap 安装包（随程序提供）和程序一并拷到该电脑，按第二节提示安装一次，再把网线插到工位网口即可；不需要安装锐捷客户端。
3. 每台电脑需要自己保存一次账号密码（保存在该用户的 Windows 凭据管理器），配置和日志不随发布包携带。
4. 首次“保存设置并更新自动化”需要管理员授权，用于创建计划任务；不需要保持界面常驻。
5. 无线模式下，需先在该电脑用 Windows 手动连接过一次 NJMU_WLAN。

五、升级、退出与停用
升级时解压到新文件夹，退出旧界面，从新目录启动并保存设置以更新任务路径；不要覆盖正在运行的文件。1.6 起主程序与自带的 NpcapBridge 必须成对升级：只替换 EXE 而不替换完整文件夹会出现“组件版本不匹配”的提示，此时请重新解压完整程序包。升级后如果“网络连接”栏再次出现“原生认证检查并验证”，请先断开校园网认证，再完成一次验证。若提示旧安装目录的进程仍在运行，请先退出旧版本程序再启动新版本。
“退出界面（自动化继续）”只关闭界面，后台任务仍运行。
停用或卸载前，选择“停止自动化并退出”，或先“停用全部自动化…”，再退出并删除完整文件夹。账号、配置和日志会保留。

本程序是个人辅助工具，不是学校官方客户端；未使用商业代码签名证书，首次运行可能出现 Windows 提示。
