# NJMU 校园网自动化连接程序

本版在保留原连接、自动恢复、计划任务、凭据存储和后台保活功能的基础上，使用连接/自动化/维护标签页及简洁的工位界面。

工位有线以本程序的原生 Npcap 认证为首要方式：“网络连接”栏的“原生认证检查并验证”只在尚未验证时显示，需离线完成一次真实验证，成功或失败都会弹窗；验证通过后该位置恢复为“立即认证并检查联网/断开校园网认证”。程序或 NpcapBridge 更新后按钮会再次出现。官方锐捷客户端 UI 自动化已移除；如本机装有官方锐捷客户端，可选择“锐捷驱动作为后备连接”，仅使用其 Rawether 驱动组件，并在“锐捷驱动检查”中以只读方式核验客户端、W64N55.dll、PCASp50 和桥程序自检，不启动客户端、不发起认证、不读取账号密码。

无线默认优先无浏览器认证，提交前失败可回退至 Chrome / Edge；账号密码明确拒绝、提交后结果不明及重复提交限制保持原策略。宿舍保持浏览器认证，不提供调查入口。

手动注销后的 5 分钟监测暂停期内点击“保存并应用”，程序会先确认是否取消暂停；确认且任务安装成功后取消，失败则保留暂停，避免设置未生效却提前恢复联网。

本次开发与回归未执行真实认证、注销或更新本机计划任务；发布包需要在目标机器验证实际联网与唤醒行为。

界面采用560×780窄高窗口、灰蓝文字层级和小型线性图标；维护页统一使用一个“打开日志”入口，帮助位于右上角。详见[使用说明](使用说明.txt)。
